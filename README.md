# unibo__projects__Olympics-hosting-advantage
Project for the Human Data Science course at University of Bologna, year 2025-2026. A study on the advantage of hosting Olympics, using statistical tools.  

Gruppo 5.  


## Usage

```bash
python src/scripts/util/plot_medals.py S USA 1
python src/scripts/util/plot_gdp.py USA 1
python src/scripts/stationary_test/adf_medals.py S USA 1
python src/scripts/stationary_test/adf_gdp.py USA 1
```
